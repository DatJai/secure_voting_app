ADMIN WORKFLOW: REGISTRATION TO TALLY
═════════════════════════════════════════════════════════════════════════════

1. ADMIN LOGS IN
   admin/adminpass → Session: admin token set, user_type="admin"

2. ADMIN REGISTERS VOTERS
   ✍️ Register Voter → Register 3 voters
   Names: Alice, Bob, Carol → System generates: VOTER-001, VOTER-002, VOTER-003

3. ADMIN ISSUES TOKENS
   🔑 Request Token → Select VOTER-001 → Issue Token

4. ADMIN RUNS VOTING (Demo)
   🗳️ Cast Vote → Select VOTER-002 → Vote for Candidate A

5. ADMIN RUNS MIXNET
   🔀 MixNet → Set layers: 5 → Run MixNet
   ⚠️ Ballots anonymized and shuffled (irreversible)

6. ADMIN VIEWS RESULTS
   📊 Tally → See votes by candidate
   Candidate A: 1 vote (but link to voter erased by MixNet)

7. ADMIN CHECKS AUDIT TRAIL
   📜 Logs → See all system events

8. ADMIN LOGS OUT
   🚪 Logout → Session cleared
